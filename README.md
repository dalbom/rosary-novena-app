# 묵주의 9일기도

- 아이폰: Safari에서 https://dalbom.github.io/rosary-novena-app/ 을 열고 공유 → **홈 화면에 추가**
- 안드로이드: 크롬에서 같은 주소를 열고 ⋮ 메뉴 → **앱 설치** (또는 홈 화면에 추가)

## 안내 (Disclaimer)

이 앱은 개인의 **묵주기도 생활을 돕기 위해** 만든 비영리 웹앱입니다.

- 광고, 유료 기능, 후원 요청이 없으며 **수익화할 계획이 없습니다.**
- 사용자의 기도 기록은 사용자의 기기(브라우저 저장소)에만 저장되며, 어떠한 서버로도 전송되지 않습니다.
- 앱에 실린 기도문의 저작권은 아래 각 저작권자에게 있습니다. 이 저장소는 기도문에 대한 어떠한 권리도 주장하지 않습니다.
  - 청원·감사 기도, 각 단 묵상 기도, 꽃다발 봉헌, 신령성체의 기도, 마침 기도: 『묵주기도로 드리는 9일기도』 ⓒ 아베마리아출판사 (2003)
  - 사도신경, 주님의 기도, 성모송, 영광송, 구원의 기도, 성모찬송: 『가톨릭 기도서』 ⓒ 한국천주교중앙협의회
- 저작권자께서 게시 중단을 원하시면 이 저장소의 Issues로 알려 주세요. 확인하는 즉시 해당 내용을 내리겠습니다.
- 이 앱은 교회의 공식 앱이 아닙니다. 기도문은 원문과 대조하여 옮겼으나, 정확한 문구는 공식 기도서를 기준으로 삼아 주세요.
